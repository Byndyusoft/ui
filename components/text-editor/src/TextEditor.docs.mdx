# TextEditor

Клиентский визуальный редактор со строковым значением Markdown для React 17+. SSR не поддерживается.
Задайте доступное имя области через `aria-label` или `aria-labelledby`. `ref`, `className`, `style`, aria/data-атрибуты и события focus/blur относятся к фактическому редактируемому div.

## Инструменты и вставка

По умолчанию доступны жирный, курсив, подчёркивание и зачёркивание. `tools` задаёт порядок без дублей; пустой массив скрывает панель. Загруженное оформление сохраняется даже при отключённом инструменте. Вставка HTML, Markdown и внутреннего clipboard очищает недоступные форматы; текст и допустимое оформление остаются. Enter после отключённого заголовка/списка создаёт абзац.

<Canvas of={Stories.DynamicTools} />
<Canvas of={Stories.LimitedPaste} />

Tab переводит фокус между областью и панелью. Стрелки и Home/End перемещают фокус внутри панели. Кнопки не отправляют форму, показывают активность через aria-pressed. Для ссылки выделите текст и откройте инструмент: Enter применяет безопасный URL, Escape отменяет и возвращает фокус. Клик по ссылке не открывает её. Undo/redo сохраняют отключённые форматы; Enter создаёт абзац/элемент списка, Shift+Enter — перенос. Специальная поддержка и проверки IME не входят в первую версию.

## Значение и уведомления

В controlled-режиме обновляйте value в немедленном onChange. Все callbacks получают строковый снимок, а не событие TextArea. Debounce (2000 мс) вызывается после паузы и завершает ожидание при unmount; throttle (1000 мс) откладывает первый вызов до конца окна и отменяется при unmount. Обработчики независимы и используют последний снимок и актуальные callbacks. Удаление обработчика, reset и внешняя замена документа отменяют соответствующие ожидания. Смена задержки применяется к следующему окну, 0 остаётся асинхронным.

## Высота, состояния и формы

Авто-высота по умолчанию выключена. withAutoHeight учитывает CSS min/max-height, padding, border и box-sizing; прокручивается только область ввода. Пересчёт выполняется после изменения документа/стилей/ширины, без ResizeObserver используется resize окна. Поздняя загрузка шрифтов отдельно не отслеживается.

name/form передают текущий Markdown в FormData сразу. Read-only разрешает фокус/выделение/копирование и отправляется; disabled исключается из Tab и отправки. Reset восстанавливает первоначальный defaultValue либо сохраняет controlled value без callbacks. Нативная constraint validation не входит в API.

## Формат хранения

Поддерживаются абзацы, H1–H6, вложенные списки, **жирный**, _курсив_, зачёркивание `~~…~~`, подчёркивание `++…++`, ссылки и принудительные переносы. Сохранение нормализует разметку и экранирует буквальные символы. Рендерер сайта должен отдельно поддерживать нестандартное `++…++`. Полный GFM, таблицы, изображения, файлы, совместное редактирование, исходный режим и произвольные extensions не входят в первую версию. Активный HTML и опасные схемы ссылок не выполняются; отображение Markdown на сайте требует безопасного рендерера.
