# `@byndyusoft-ui/text-editor`

Визуальный редактор Markdown для React 17+. Компонент предназначен для клиентского монтирования; SSR и гидратация в первой версии не поддерживаются.

```tsx
import React, { useState } from 'react';
import TextEditor from '@byndyusoft-ui/text-editor';

function Description() {
    const [value, setValue] = useState('');
    return (
        <TextEditor
            value={value}
            onChange={setValue}
            onDebouncedChange={markdown => console.log(markdown)}
            aria-label="Описание"
            name="description"
            withAutoHeight
            style={{ minHeight: 120, maxHeight: 400 }}
        />
    );
}
```

`TextEditor` также экспортируется по имени. Публичные типы: `ITextEditorProps`, `TTextEditorTool`. `ref` указывает на фактический редактируемый `HTMLDivElement`, появляется после клиентской инициализации и очищается при размонтировании. Начальная загрузка не вызывает обработчики изменения.

## Значение и инструменты

Выберите controlled `value` + **немедленный** `onChange` либо uncontrolled `defaultValue`. Не переключайте режим после монтирования. Последующие изменения `defaultValue` игнорируются, включая сброс: он восстанавливает первоначальное значение. Обычный echo из `onChange` сохраняет курсор, историю и ожидающие уведомления. Настоящая внешняя замена `value` отменяет уведомления прежнего документа, начинает новую историю и не вызывает callbacks.

```tsx
<TextEditor
    defaultValue={'# Заголовок\n\n++Подчёркнутый++ текст'}
    tools={['bold', 'italic', 'underline', 'strike', 'heading', 'orderedList', 'bulletList', 'link']}
    aria-label="Статья"
/>
```

| Prop                                                                | Default                                     | Значение                                                                         |
| ------------------------------------------------------------------- | ------------------------------------------- | -------------------------------------------------------------------------------- |
| `tools`                                                             | `['bold', 'italic', 'underline', 'strike']` | Разрешённые инструменты; readonly-массив, порядок первого вхождения, без дублей  |
| `value`, `defaultValue`                                             | `undefined`, `''`                           | Строка Markdown                                                                  |
| `onChange`                                                          | —                                           | Немедленный `(markdown: string) => void`                                         |
| `onDebouncedChange`, `debounceDelay`                                | —, `2000`                                   | Последний снимок после паузы                                                     |
| `onThrottledChange`, `throttleDelay`                                | —, `1000`                                   | Последний снимок в конце окна                                                    |
| `withAutoHeight`                                                    | `false`                                     | Рост и уменьшение области ввода                                                  |
| `isDisabled`, `isReadOnly`                                          | `false`                                     | Запрет редактирования; disabled имеет приоритет и исключает поле из Tab/отправки |
| `placeholder`                                                       | `''`                                        | Подсказка пустого документа                                                      |
| `name`, `form`                                                      | —                                           | Имя поля и id внешней формы                                                      |
| `id`, `className`, `style`, `aria-*`, `data-*`, `onFocus`, `onBlur` | —                                           | Свойства фактической области ввода                                               |

Абзацы доступны всегда. `heading` включает H1–H6. `tools={[]}` скрывает панель. Смена набора не пересоздаёт документ. Уже сохранённое поддерживаемое оформление отображается и сохраняется даже при отсутствующем инструменте; ввод внутри такого фрагмента сохраняет формат. Создать новое оформление через панель, shortcuts или правила ввода нельзя. Enter после отключённого заголовка/списка создаёт абзац. Undo/redo восстанавливают оформление независимо от `tools`.

При вставке HTML (приоритетный формат), обычного текста с Markdown или внутреннего содержимого редактора снимаются недоступные marks; заголовок превращается в абзац, запрещённый тип списка — в абзацы элементов с рекурсивной обработкой вложенности. Разрешённые форматы и порядок текста сохраняются. Вставка в отключённый форматированный фрагмент не наследует его оформление. Фильтрация относится к буферу, а загрузка `value` использует полную схему.

## Диалект Markdown

Поддерживаются `**жирный**`, `*курсив*`, `++подчёркнутый++`, `~~зачёркнутый~~`, абзацы, принудительные переносы, заголовки `#`–`######`, вложенные `-` и нумерованные списки с начальным номером, `[ссылки](/path)`. Enter создаёт абзац/элемент списка, Shift+Enter — принудительный перенос. Разметку можно сочетать. Пустой документ сериализуется в `''`.

Сериализация нормализует маркеры, отступы, экранирование и пробелы, сохраняя смысл поддерживаемого документа. Буквальные `++` и другие значимые символы экранируются; пробелы внутри подчёркивания могут записываться числовыми HTML-сущностями. Побайтовое совпадение входа и выхода не гарантируется. Это подмножество Markdown, а не полный GFM: нет изображений, таблиц, code/blockquote, файлов или произвольных HTML-узлов. Неподдерживаемые структуры приводятся к доступному тексту/схеме. Активный HTML не выполняется.

**Рендерер сайта должен отдельно поддерживать `++…++`**: стандартный CommonMark/GFM не имеет такого подчёркивания. Компонент отображения Markdown в пакет не входит. При отображении данных на сайте требуется собственная безопасная обработка Markdown. В редакторе разрешены ссылки `http:`, `https:`, `mailto:`, `tel:`, относительные пути и фрагменты; опасные схемы и управляющие символы отклоняются.

## Уведомления

Все callbacks получают неизменяемый **строковый снимок**, а не React/DOM-событие TextArea. Документ и FormData обновляются сразу; задержки относятся только к уведомлениям. Фокус, выделение, смена `tools` и внешнее значение не вызывают `onChange`.

Debounce перезапускает ожидание при каждом изменении и завершает ожидающий вызов один раз при unmount. Throttle использует `leading: false, trailing: true`: первый вызов отложен, новое изменение заменяет снимок без сдвига конца окна. При unmount throttle отменяется. Они независимы, регистрируются до `onChange` и используют актуальные callbacks. Удаление обработчика отменяет очередь, замена сохраняет срок. Новая задержка применяется к следующему окну; `0` остаётся асинхронным, отрицательное/нечисловое/бесконечное значение заменяется default. Внешняя замена документа и reset отменяют обе очереди.

## Высота и формы

`withAutoHeight` по умолчанию выключен, как в TextArea. При включении область растёт и уменьшается с учётом padding, border, box-sizing и CSS `minHeight`/`maxHeight`. При достижении максимума прокручивается область ввода; панель остаётся снаружи. Изменения ширины обрабатываются ResizeObserver, без него — событием resize окна. Скрытая область измеряется после появления; поздняя загрузка шрифтов отдельно не отслеживается. При отключении/размонтировании стили высоты/overflow/resize восстанавливаются.

`name` добавляет hidden input с актуальным Markdown. `form` связывает его с внешней формой по id. Read-only включается в FormData, disabled исключается. Reset восстанавливает первоначальный `defaultValue` в uncontrolled-режиме либо сохраняет `value` в controlled без change callbacks. При смене `form` подписка сброса переносится. Нативные `required`, `minLength`, `maxLength` и constraint validation не поддерживаются; валидацию выполняет форма.

Укажите доступное имя через `aria-label` или `aria-labelledby`. Область имеет `role="textbox"`, `aria-multiline`, состояния aria-disabled/readonly. Read-only позволяет фокус, выделение и копирование. Панель доступна через Tab; стрелки, Home/End перемещают фокус между инструментами. Кнопки имеют `type="button"` и `aria-pressed`. Ссылка редактируется в поле URL: Enter применяет, Escape отменяет и возвращает фокус. Обычный клик по ссылке в редакторе не открывает её. Работают стандартные shortcuts форматирования и undo/redo. Специальная поддержка и проверки IME не входят в первую версию; используется базовое поведение Tiptap.

## Совместимость и разработка

Tiptap core/pm/react/markdown/starter-kit/placeholder закреплены на **3.32.0**. Проверки с React/ReactDOM 17.0.2 подтверждают клиентское монтирование, публичный DOM-ref, редактирование и очистку. Markdown/clipboard fixtures проверяют все форматы, H1–H6, смешанные marks, экранирование и вложенные списки.

Сборочный TypeScript закреплён на **5.4.5**: Tiptap 3.7.0 и 3.32.0 не проходят TS 4.9.5 из-за `NoInfer` и getter/setter `content`, но проходят проверку импортов и локальных adapters с `strict: true`, `skipLibCheck: false`. Публичные декларации компонента не экспортируют типы движка; их потребление TS 4.9 проверяется отдельно. Версии существующих зависимостей, кроме согласованного TypeScript, сохранены. typescript-eslint 5.62 формально поддерживает TS ниже 5.2; фактические линтеры проверяются с установленной связкой.

ESM-импорт @tiptap/react с React 17 в Node не разрешает `react/jsx-runtime`; SSR не входит в первую версию по решению пользователя. Клиентский bundler корректно разрешает этот импорт. Vitest обрабатывает @tiptap/react через Vite для проверки клиентского поведения.

Команды из корня:

```sh
npx --no-install turbo run build --filter='@byndyusoft-ui/text-editor...'
npm test -- components/text-editor/src
npm run lint:check --workspace=@byndyusoft-ui/text-editor
npm run build-storybook
npm start
```

У общей сборки ранее воспроизведено зависание Rollup пакета Flex после создания dist и с TS 4.9.5, и с TS 5.4.5. Проверка нового пакета с его зависимостями не требует Flex.

В разовой Rollup-сборке нового пакета отключены только файловые подписки внутренней watch-программы TypeScript: на macOS они могли сохраняться после завершения emit. Начальная проверка типов и выпуск деклараций выполняются полностью; watch-режим сохраняет обычный compiler host. Отрицательная проверка с временной ошибкой `TS2322` подтвердила сохранение диагностики; проверочный файл удалён, итоговая сборка выполнена с очисткой.

Подробные результаты проверок и ограничения — в [VERIFICATION.md](VERIFICATION.md).
