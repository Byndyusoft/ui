## Пересмотр реализации

-   StarterKit расширяется через публичный `this.parent`, без вызова `StarterKit.config.addExtensions` с искусственным контекстом. Удалён дублирующий перечень горячих клавиш: ограничения накладываются на унаследованные обработчики, включая их uppercase-варианты.
-   Обычный Enter обрабатывает Tiptap. Специальный обработчик нужен только для отключённых marks/heading/list. Общий ручной конвейер промежуточных состояний заменён цепочкой штатных команд; небольшой мост остался для liftListItem, которому требуется отдельный mapping. Регрессия проверяет выход из вложенных отключённых списков и восстановление одним Undo.
-   Проверены native Enter с разрешёнными списками/marks, Tab/Shift+Tab и динамическое отключение этих действий. Ref передаётся через обычный useImperativeHandle; первичная загрузка и внешняя замена используют общий путь.
-   Специальный guard композиции, композиционные тесты и история Composition удалены. Отдельная проверка Shift+Enter сохранена. IME не является критерием приёмки.

## Браузерная проверка

Проверка проведена в in-app браузере через локальный Storybook на порту 6009 с фактически собранным пакетом. После пересмотра повторно проверены Enter в разрешённом списке и Undo, сохранность вложенных списков при отключении tools, выход из отключённого вложенного списка и Undo, HTML-вставка внутрь сохранённого жирного фрагмента без наследования запрещённого оформления. Ниже также перечислены проверки, проведённые до пересмотра:

-   Выделение сохраняется при действиях панели; четыре inline-инструмента сочетаются, активность отражается в aria-pressed. H1–H6 дают соответствующие DOM-заголовки; нумерованный список переключается в маркированный.
-   Проверены keyboard undo/redo и ограничения shortcuts/input rules: `**обычный**`, `# заголовок` и ввод после запрещённого Mod-B остаются обычным текстом.
-   Интерфейс ссылки сохраняет диапазон и возвращает фокус после применения. Автотесты дополнительно покрывают отклонение опасного URL, отмену, удаление, стрелки панели и смену tools при открытом интерфейсе.
-   Внутреннее копирование из полного редактора в ограниченный снимает heading/list/inline-форматы, оставляя разрешённый курсив. Отдельно проверены text/plain Markdown и внешний text/html. Вставка внутри существующего жирного фрагмента не наследует его; окружающее оформление остаётся. Один undo отменяет вставку.
-   Область авто-высоты выросла с 100 до 240px при scrollHeight 1748px и overflow auto; после удаления вернулась к 100px и overflow hidden. Панель остаётся вне прокрутки.
-   Отправка формы сразу вернула `**Новое значение**`; reset восстановил начальный текст. Read-only позволил выделить и скопировать текст, ввод его не изменил; disabled имеет tabIndex -1 и contenteditable false.
-   В controlled-примере `++снимок++` появился сразу, затем один раз пришёл в debounce и throttle. Обновление родительского value не сбросило документ.

## Сборка и ограничения

Разовая Rollup-сборка могла оставлять FSWatcher/StatWatcher после emit: диагностика собственного процесса выявила открытые файловые подписки. В конфигурации только нового пакета для разовой сборки TypeScript получает sys без постоянных файловых подписок. При `ROLLUP_WATCH=true` используется обычный sys. Первичная компиляция и диагностика не отключены: временная ошибка `string = 1` была обнаружена как TS2322. Проверочный source удалён, dist очищен и заново собран; посторонних исправлений общих конфигураций не внесено.

Все Tiptap subpaths остаются внешними Rollup dependencies: дополнительная копия ProseMirror приводила к коллизии keyed plugins. После исправления пакет проверен через публичный импорт в Storybook.

Специальная поддержка и проверки IME исключены пользователем; используется базовое поведение Tiptap. SSR и гидратация исключены пользователем из первой версии: ESM-импорт @tiptap/react с React 17 в Node не разрешает react/jsx-runtime. Клиентский bundler разрешает его; Vitest обрабатывает этот клиентский пакет через Vite. Поздняя загрузка шрифтов отдельно не отслеживается. Для показа Markdown на сайтах нужны безопасный renderer и поддержка `++…++`.

Общая сборка всех старых пакетов ранее зависала после emit Flex и с TS 4.9.5, и с TS 5.4.5. Эта отдельная проблема не исправлялась; финальная проверка TextEditor использует его граф из 7 пакетов. Сохраняются предупреждения устаревшей базы Browserslist, размера некоторых Storybook chunks и отдельные предупреждения существующих правил линтера; обновление других зависимостей не выполнялось.
