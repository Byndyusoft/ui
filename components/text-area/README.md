# `@byndyusoft-ui/text-area`

React-компонент на основе нативного `<textarea>` с двумя видами отложенных коллбеков и автоматической высотой.

## Установка

```sh
npm install @byndyusoft-ui/text-area
```

## Использование

```tsx
import React, { useState } from 'react';
import TextArea from '@byndyusoft-ui/text-area';

const Example = (): JSX.Element => {
    const [value, setValue] = useState('');

    return (
        <TextArea
            aria-label="Описание"
            value={value}
            onChange={event => setValue(event.target.value)}
            onDebouncedChange={event => console.log('После паузы:', event.target.value)}
            debounceDelay={600}
            onThrottledChange={event => console.log('С ограничением частоты:', event.target.value)}
            throttleDelay={400}
            withAutoHeight
            rows={3}
            style={{ minHeight: 80, maxHeight: 240 }}
        />
    );
};
```

Компонент поддерживает управляемый режим через `value` и обычный режим через `defaultValue`. Нативные атрибуты и обработчики передаются в DOM. Через `ref` доступен `HTMLTextAreaElement`; оформление задаётся через `style` и `className`.

Доступны экспорт по умолчанию, именованный экспорт `TextArea` и тип `ITextAreaProps`.

## Пропсы

| Пропс               | Тип                                       | По умолчанию | Поведение                                                |
| ------------------- | ----------------------------------------- | ------------ | -------------------------------------------------------- |
| `isDisabled`        | `boolean`                                 | `false`      | Устанавливает нативный `disabled`.                       |
| `onChange`          | `ChangeEventHandler<HTMLTextAreaElement>` | отсутствует  | Вызывается сразу при пользовательском изменении.         |
| `onDebouncedChange` | `ChangeEventHandler<HTMLTextAreaElement>` | отсутствует  | Вызывается после полной паузы во вводе.                  |
| `debounceDelay`     | `number`                                  | `2000`       | Длительность паузы в миллисекундах.                      |
| `onThrottledChange` | `ChangeEventHandler<HTMLTextAreaElement>` | отсутствует  | Вызывается с задержкой, не чаще одного раза за интервал. |
| `throttleDelay`     | `number`                                  | `1000`       | Интервал ограничения частоты в миллисекундах.            |
| `withAutoHeight`    | `boolean`                                 | `false`      | Включает рост и уменьшение высоты по содержимому.        |

Вместо нативного пропса `disabled` используется `isDisabled`.

## Коллбеки

### После паузы: debounce

Каждое пользовательское изменение сохраняет последнее событие и перезапускает таймер. `onDebouncedChange` выполняется, когда ввод прекратился на весь `debounceDelay`.

При размонтировании последнее ожидающее событие передаётся обработчику один раз, без ожидания оставшегося времени. Если ожидания нет, обработчик не вызывается.

### Ограничение частоты: throttle

Первое изменение запускает окно `throttleDelay`; немедленного вызова нет. Следующие изменения заменяют ожидающее событие, сохраняя срок окна. В конце окна `onThrottledChange` получает последнее событие.

Новое окно начинается с первого изменения после предыдущего вызова. Поэтому непрерывный ввод вызывает обработчик не чаще одного раза за интервал. При размонтировании ожидание отменяется.

### Общие правила

-   Интервалы независимы; оба коллбека можно использовать одновременно.
-   `onChange` сохраняет нативное поведение и вызывается сразу. Ожидания регистрируются до него, поэтому синхронное размонтирование внутри `onChange` завершает debounce и отменяет throttle.
-   Без соответствующего отложенного обработчика новый таймер для него не запускается.
-   Удаление отложенного обработчика отменяет его таймер и ожидающее событие. Повторное включение не восстанавливает старое событие. Замена одного обработчика другим сохраняет срок ожидания и использует актуальную функцию.
-   Изменение `value` через пропсы не запускает коллбеки. При включённой авто-высоте оно пересчитывает размер поля.
-   Ожидающий вызов использует актуальный обработчик из пропсов. Изменение интервала сохраняет срок текущего таймера; новый интервал используется при следующем запуске.
-   Задержка `0` означает асинхронный вызов через таймер. Отрицательные, бесконечные и нечисловые значения заменяются значениями по умолчанию.

Все обработчики получают исходное React-событие. Оно сохраняется по ссылке: `event.target.value` отражает значение DOM на момент выполнения, включая программные изменения после ввода. После завершения синхронного обработчика `event.currentTarget` становится `null`. Для сохранения значения именно на момент ввода скопируйте строку внутри `onChange`.

## Автоматическая высота

При `withAutoHeight` поле растёт и уменьшается по содержимому. `rows` задаёт минимальное количество строк; без него используется нативный минимум — две строки. CSS `minHeight` и `maxHeight` задают дополнительные границы по обычным правилам CSS, включая приоритет минимальной высоты при противоречащих ограничениях.

Расчёт учитывает padding, border и `box-sizing`. При достижении максимальной высоты появляется вертикальная прокрутка. Ручное изменение размера отключается. При выключении флага восстанавливаются пользовательские высота, overflow и resize.

Высота пересчитывается при вводе и сбросе формы, а также при изменении `value`, `rows`, `style`, `className` или ширины поля. Изменения только высоты не запускают повторное измерение через `ResizeObserver`. При отсутствии этого API используется событие изменения размера окна.

Загрузка шрифтов после первоначального измерения пока не учитывается: компонент не отслеживает её завершение и не запускает отдельный пересчёт высоты. Если загруженный шрифт изменит переносы или высоту строк, размер поля обновится при следующем обычном пересчёте, например при вводе текста.

Фокус, выделение и DOM-элемент сохраняются. Скрытое поле измеряется после повторного отображения. При серверном рендере измерения не выполняются; высота рассчитывается в браузере.
