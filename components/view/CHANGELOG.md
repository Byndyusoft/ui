# @byndyusoft-ui/view

## 1.0.0

### Major Changes

-   10d25a8: Конфигурация сетки теперь задаёт фиксированный шаг как `{ value, unit }` с единицами `px` или `rem`, а CSS-классы получают готовые длины без runtime-переменной. Добавлен настраиваемый prefix CSS-классов с default `bsui`.
-   943b971: Параметр конфигурации `grid` переименован в `values`. Упорядочены реализации View и Flex,
    обновлены экспорты, типы и документация.
-   0b08fb6: Удалён устаревший API раскладки: default-экспорты `View` и `Flex`, типы `IViewProps`, `IFlexProps`, `TSpacingUnit`, фиксированная сетка `su*` и пакет `@byndyusoft-ui/css-utilities`. Пакеты ранее не публиковались, внешних потребителей нет. Миграция — фабрики `createView(config)` и `createFlex(view)`: задайте собственный юнит и сетку токенов, например `createView({ unit: '1rem', grid: { '025': 0.25, '100': 1, '300': 3 } } as const)`, и используйте созданные компоненты вместо готовых.

### Minor Changes

-   9cbd934: Добавлены короткие aliases spacing-пропсов, определён приоритет пересекающихся отступов и схлопывание одинаковых токенов в компактные CSS-классы.
-   0b08fb6: Добавлены фабрики `createView(config)` и `createFlex(view)`: компоненты раскладки под собственную сетку отступов проекта (юнит и именованные токены-множители), с выводом типов из конфигурации, автогенерацией CSS без inline-стилей, автоинъекцией стилей и компонентом `LayoutStyles` для SSR. Существующие `View`/`Flex` и сетка `su*` не изменились.
