# Spec Delta

## REMOVED Requirements

### Requirement: Совместимость с существующим API

**Reason**: Старые классовые `View`/`Flex`, тип `TSpacingUnit` и классовая схема `su*` удаляются из библиотеки: фабрики `createView`/`createFlex` полностью замещают их, а пакеты никогда не публиковались — внешних потребителей нет. Сосуществование двух API больше не поддерживается.

**Migration**: Вместо default-экспортов `View`/`Flex` и токенов `su*` потребители создают компоненты через `createView(config)`/`createFlex(view)` из `@byndyusoft-ui/view` и `@byndyusoft-ui/flex`, задавая собственную сетку. Бывшая сетка `su025`–`su1000` воспроизводится конфигурацией `{ unit: '1rem', grid: { '025': 0.25, '050': 0.5, ... } }` при необходимости сохранить значения один в один.
