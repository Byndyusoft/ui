# Proposal

## Why

Компоненты `View` и `Flex` задают отступы через фиксированную сетку `su025`–`su1000`, зашитую одновременно в TS-типах (`TSpacingUnit`), SCSS-переменных и сгенерированных CSS-классах. Проект-потребитель может переопределить значение юнита и шагов через CSS-переменные, но не может изменить состав сетки: набор токенов и их имена жёстко определены библиотекой, а четыре дублирующих списка в коде уже дали рассинхрон (`--su175` есть в CSS, но отсутствует в типах). Проектам нужны собственные сетки — и по шагу юнита, и по составу значений — с сохранением типизации.

## What Changes

- Добавить в `@byndyusoft-ui/view` фабрику `createView(config)`: принимает конфигурацию (`unit`, произвольный именованный набор множителей `grid`), возвращает компонент `View`, типизированный токенами этой сетки (вывод типов из конфига, без кодогенерации).
- Добавить в `@byndyusoft-ui/flex` фабрику `createFlex(view)`, принимающую экземпляр, созданный `createView`: сетка и её тип выводятся из переданного `View`, что исключает рассинхрон конфигураций.
- Реализовать генерацию чистого CSS (без SCSS) из конфигурации в рантайме: утилитарные классы отступов для `View`, классы gap и фиксированные flex-модификаторы для `Flex`, все значения через `calc(var(--bsui-unit, <unit>) * <multiplier>)`.
- Доставить CSS в рантайме без build-time пайплайна: автоинъекция `<style>` при импорте модуля для SPA и React-компонент стилей для SSR (стили в серверном HTML, без дублей после гидратации).
- Сохранить рантайм-переопределяемость юнита через CSS-переменную (поддеревья, медиа-запросы, темы).
- Существующие экспорты `View`/`Flex` и классовая схема `su*` не изменяются — новый API добавочный, breaking changes нет.

## Capabilities

### New Capabilities

- `configurable-layout`: фабрики `createView`/`createFlex`, создающие типизированные компоненты раскладки из проектной конфигурации сетки, и генерация CSS под эту сетку с двумя режимами доставки.

### Modified Capabilities

(пусто — существующее поведение `View`/`Flex` не меняется)

## Impact

- `components/view`: новый публичный API `createView`, типы конфигурации, генератор CSS отступов, механизм инъекции; существующий `View` по умолчанию не затрагивается.
- `components/flex`: новый публичный API `createFlex`, генерация gap-классов из той же сетки; существующий `Flex` не затрагивается.
- Тесты: юнит-тесты генератора CSS, типовые тесты (`*.tests-d.ts`) вывода токенов из конфига, тесты рендера и инъекции стилей, SSR-тесты (стили в HTML при серверном рендере через компонент стилей, node-безопасность инъектора, отсутствие дублей после гидратации).
- Storybook и README обоих пакетов: документация нового API.
- Changesets: `minor` для `@byndyusoft-ui/view` и `@byndyusoft-ui/flex`.
- Совместимость: React 17, TypeScript 4.9 (`as const` на конфиге, без `const`-параметров дженериков из TS 5.0).
