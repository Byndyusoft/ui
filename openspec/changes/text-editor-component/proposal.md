# Proposal

## Why

В Byndyusoft UI есть поля для обычного текста, но нет визуального редактора форматированного содержимого для форм. Нужен единый компонент, который сохраняет Markdown, позволяет ограничивать инструменты для каждого поля и поддерживает отложенные уведомления и автоматическую высоту, знакомые по TextArea.

## What Changes

-   Добавить пакет `@byndyusoft-ui/text-editor` в `components/text-editor` с компонентом `TextEditor`, публичными типами, тестами, README и Storybook.
-   Поддержать визуальное редактирование жирного, курсивного, подчёркнутого и зачёркнутого текста, абзацев, нумерованных и ненумерованных списков и ссылок. Внешнее значение — Markdown; подчёркивание записывается как `++текст++`.
-   Добавить `tools` для каждого поля. По умолчанию доступны только `bold`, `italic`, `underline`, `strike`; абзацы остаются базовой структурой документа.
-   Загружать и сохранять все поддерживаемые форматы независимо от `tools`. Ограничивать создание нового оформления через панель, горячие клавиши и автоматическое преобразование ввода. При вставке снимать недоступное оформление, сохраняя текст, порядок и разрешённые форматы.
-   Поддержать `value` / `defaultValue`, немедленный `onChange` и независимые debounce/throttle callbacks со строковым снимком Markdown и временными правилами TextArea.
-   Добавить авто-высоту с CSS-ограничениями, состояния disabled/read-only, DOM-ref, доступное управление клавиатурой и безопасный серверный рендеринг; поддержать `name`/`form`, актуальное значение в FormData и сброс связанной формы.
-   Сохранить совместимость с React 17 и TypeScript 4.9, добавить changeset для нового публикуемого пакета.

Первая версия не включает изображения, таблицы, файлы, совместное редактирование, режим исходного Markdown, произвольные расширения движка или точное сохранение исходного написания Markdown. Поддерживается согласованное подмножество Markdown, а не произвольный документ GFM. Существующие API TextArea, TextInput и hook-пакетов не меняются.

## Capabilities

### New Capabilities

-   `text-editor`: визуальное редактирование Markdown в формах, управление доступными инструментами и вставкой, уведомления об изменениях, размеры и доступность поля.

### Modified Capabilities

Нет. Основные спецификации OpenSpec пока отсутствуют; поведение существующих компонентов не изменяется.

## Impact

-   Новый workspace `components/text-editor`; корневой `package-lock.json` обновляется при установке его зависимостей на этапе реализации. Корневой glob `components/*` уже включает пакет.
-   Именованный/default экспорт `TextEditor`, типы `ITextEditorProps` и `TTextEditorTool`; `ref` на редактируемый `HTMLDivElement`. Callback изменения принимает Markdown, а не нативное событие textarea.
-   Движок Tiptap 3 / ProseMirror и Markdown-адаптер; существующие `use-debounced-callback`, `use-throttled-callback`, `use-latest-ref`, `use-isomorphic-layout-effect` и при необходимости `use-resize-observer` подключаются через публичные workspace-импорты. Совместимая конкретная версия движка проверяется до основной реализации.
-   README и истории нового пакета должны описывать диалект Markdown, правила `tools`, вставку и отличия callback от TextArea. Сайты, отображающие значение, должны поддерживать `++…++`; отдельный компонент просмотра Markdown в эту работу не входит.
-   Проверки нового пакета: runtime/SSR/type tests, линтеры, сборка с зависимостями, сборка и браузерная проверка Storybook. Генерируемые артефакты не коммитятся.
