# Proposal

## Why

`View` и `Flex` повторяют `calc()` для каждого токена и варианта spacing, хотя базовый шаг известен при вызове `createView`. Фиксированный шаг позволит генерировать готовые CSS-длины, а настраиваемый префикс — изолировать классы разных конфигураций сетки.

## What Changes

-   **BREAKING**: заменить строковое поле `unit` конфигурации на `step: { value, unit }`, где `value` — положительное целое число, а `unit` — `'px' | 'rem'`.
-   Предварительно вычислять CSS-длины из шага и множителей `values`, сохраняя поддержку дробных множителей; удалить зависимость сгенерированных отступов от `calc()` и runtime-переменной `--bsui-unit`.
-   Добавить необязательный `prefix` для CSS-классов с default `'bsui'`; применять его к spacing-классам `View`, gap-классам и модификаторам `Flex`.
-   Обновить документацию, истории, тесты и требования конфигурируемой раскладки для новой конфигурации и генерации CSS.

### New Capabilities

### Modified Capabilities

-   `configurable-layout`: конфигурация шага, вычисление фиксированных CSS-длин, удаление runtime-переопределения шага и настройка префикса классов.

## Impact

-   Публичные типы и фабрики `createView` / `createFlex` в `components/view` и `components/flex`.
-   CSS-генераторы и получение имён классов в обоих пакетах; default-префикс сохраняет существующий namespace `bsui`.
-   README, Storybook и runtime/type tests пакетов View и Flex.
-   Потребители конфигурации должны перейти со строкового `unit` на объект `step`; переопределение `--bsui-unit` больше не влияет на отступы.
